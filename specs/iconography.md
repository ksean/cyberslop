# Iconography

The intended silhouette of each of the forty-four item icons (PROD-049). Whether an icon is
recognisable is a human judgement made against the icon sheet; this catalog is what the sheet is
judged against. Icons are composed from shared parts (`grip`, `stock`, `muzzle`, `ring`,
`Icon.cased`) so that "every pistol has a grip" is a function rather than a coincidence. A weapon
uses three to ten strokes; a powerup four to eight inside its four-stroke casing.
